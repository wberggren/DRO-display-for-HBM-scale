This arduino sketch is for an arduino nano and an 1.3 inch oled display
to replace the difficult to read LCD display of an HBM DRO (digital read out) set 
for a lathe. The HBM sensor + scale are kept in place and the connector from 
the HBM sensor is now plugged in the new display housing. The old HBM display 
can still be used if required.
The other disadvantage of the HBM display is that it is powered by 
2 parallel 2032 3V coin type batteries. These batteries have to be replaced
too often. The new design can be powered with a simple 5V power supply so that
batteries are no longer required.
Note: the DRO.fzz file can be opened with Fritzing and shows diagram + PCB
